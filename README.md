# 武汉市公共文化设施分析系统

这是一个基于Python Flask和MySQL的武汉市公共文化设施（图书馆、博物馆等）使用分析系统，用于数据库课程设计。

## 项目概述

本系统对武汉市主要公共文化设施进行数据分析，功能包括：

- 各文化场馆的访客流量趋势分析
- 不同类型展览/活动的受欢迎程度分析
- 访客画像分析（不同年龄段、职业人群的偏好）
- 场馆信息查询与展示
- 活动预约功能模拟
- 访客反馈数据分析

## 数据库设计

系统使用MySQL数据库，主要包含以下表：

- `Venues`: 存储场馆信息（ID、名称、类型、地址、开放时间等）
- `Exhibitions_Events`: 存储展览和活动信息（ID、场馆ID、名称、时间、描述等）
- `Visitors`: 存储访客信息（ID、年龄段、职业类型）
- `Venue_Visits`: 存储访问记录（场馆ID、访客ID、日期、参与活动）
- `Event_Reservations`: 存储活动预约记录

## 技术栈

- 后端：Python Flask
- 数据库：MySQL
- 前端：HTML, CSS, JavaScript, Bootstrap 5
- 数据可视化：ECharts
- 地图功能：高德地图API

## 安装与运行

### 前提条件

- Python3.8+
- MySQL 8.0
- pip包管理工具

### 安装步骤

1. 克隆项目仓库
   ```
   git clone https://github.com/your-username/wuhan-cultural-facilities.git
   cd wuhan-cultural-facilities
   ```

2. 安装依赖
   ```
   pip install -r requirements.txt
   ```

3. 配置数据库
   - 修改`app.py`中的数据库连接信息
   - 执行schema.sql创建数据库结构
   ```
   mysql -u username -p < schema.sql
   ```

4. 生成模拟数据
   ```
   python generate_data.py
   ```

5. 启动应用
   ```
   python app.py
   ```

6. 在浏览器中访问 http://localhost:5000

## 功能模块

### 1. 场馆地图

展示武汉市各公共文化设施的地理分布，支持点击查看详情。

### 2. 数据分析

提供多维度的数据分析图表：
- 访客流量趋势
- 场馆类型访问量分布
- 访客年龄分布
- 不同职业访客的场馆偏好
- 活动类型受欢迎程度
- 访问时间分布
- 最受欢迎的展览/活动排行

### 3. 展览活动

展示当前及即将举行的展览和活动，支持按类型和场馆筛选。

### 4. 参观预约

提供活动预约功能，包括：
- 访客信息登记
- 活动预约
- 我的预约管理
- 访问记录和反馈提交

### 5. 访客反馈

分析访客反馈数据，包括：
- 场馆满意度排名
- 访客反馈词云
- 最新访客反馈展示

## 数据模拟说明

由于本系统为课程设计项目，数据为模拟生成：

- 场馆数据基于武汉市实际公共文化设施
- 访客数据随机生成但保持合理的人口特征分布
- 访问记录和活动数据基于合理的时间和偏好模式生成
